# Flow Space

Flow Space — рабочее пространство для управления задачами и командой. В приложении есть канбан-доска, приоритеты, сроки, KPI, шаблоны задач, AI-помощники, тёмная тема и синхронизация через Firebase.

## Возможности

- личный и командный режимы;
- четыре статуса задач, приоритеты, сроки и оценка времени;
- шаблоны для маркетинга, продаж, разработки и юридических задач;
- AI-помощники через серверный endpoint `/api/ai`;
- авторизация и хранение данных в Firebase;
- уведомления и интеграция с Telegram.

## Локальный запуск

Требуется Node.js 18 или новее.

```bash
npm ci
npm start
```

Приложение откроется по адресу <http://localhost:3000>.

## Переменные окружения

Создайте `.env.local` и задайте параметры Firebase, используемые в `src/firebase.js`. Секретные ключи AI и Telegram должны храниться только в переменных окружения серверных функций, а не в клиентском коде.

## Проверка перед публикацией

```bash
npm test -- --watchAll=false
npm run build
```

Проект подготовлен для Vercel; серверные обработчики находятся в каталоге `api`.

## Структура

- `src/App.js` — основной экран и бизнес-логика интерфейса;
- `src/config.js` — переводы, KPI, шаблоны и стандартные автоматизации;
- `src/firebase.js` — подключение Firebase;
- `api/ai.js` — серверный прокси для AI;
- `api/telegram.js` — серверная интеграция Telegram.

`App.js` всё ещё крупный. Новые функции рекомендуется выносить в компоненты, хуки и сервисы.
