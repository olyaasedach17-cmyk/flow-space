# Flow Space

Flow Space — рабочее пространство для управления задачами и командой: канбан-доска, приоритеты, сроки, KPI, шаблоны, AI-помощники и синхронизация через Firebase.

## Возможности

- личный и командный режимы;
- четыре статуса задач, приоритеты, сроки и оценка времени;
- шаблоны для маркетинга, продаж, разработки и юридических задач;
- AI-помощники через серверный endpoint `/api/ai`;
- авторизация и хранение данных в Firebase;
- уведомления и интеграция с Telegram.

## Локальный запуск

Требуется Node.js 18 или новее.

```bash
npm ci
npm start
```

## Проверка перед публикацией

```bash
npm test -- --watchAll=false
npm run build
```

Проект подготовлен для Vercel; серверные обработчики находятся в каталоге `api`.

## Структура

- `src/App.js` — основной экран и бизнес-логика;
- `src/config.js` — переводы, KPI, шаблоны и автоматизации;
- `src/firebase.js` — подключение Firebase;
- `api/ai.js` и `api/telegram.js` — серверные интеграции.

`App.js` всё ещё крупный. Новые функции рекомендуется выносить в компоненты, хуки и сервисы.
