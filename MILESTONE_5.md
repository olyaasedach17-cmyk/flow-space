# Flow Space — Milestone 5

## Executive Decision Layer

Milestone 5 превращает Executive Overview из обычного списка рисков в интерфейс управления по исключениям.

### Что добавлено

- Risk Engine теперь классифицирует сигналы в три управленческие группы:
  - **Можно не трогать** — штатная работа и здоровая часть операционки.
  - **Команда решает сама** — вопросы руководителя/команды, которые не должны эскалироваться собственнику.
  - **Нужно ваше решение** — только системные исключения, где нужен выбор владельца.
- Добавлена отдельная группа **Наблюдать, но не вмешиваться** для информационных сигналов.
- Executive Overview перестроен вокруг этих трёх решений вместо ленты проблем.
- Executive AI получает уже классифицированные факты и обязан сохранять границу между операционкой команды и решениями собственника.
- При отсутствии owner-level исключений интерфейс прямо говорит, что вмешательство собственника не требуется.
- Добавлены тесты на корректную эскалацию: единичная просрочка остаётся у команды, системная просрочка эскалируется владельцу.

### Текущие детерминированные пороги

- 1–2 просроченных результата → команда.
- 3+ просроченных результата → решение собственника.
- загрузка 24–39 ч активной оценённой работы → команда перераспределяет;
- 40+ ч → собственник выбирает приоритет/ресурс/срок;
- повторная доработка 2+ раз → owner-level исключение;
- очередь из 2+ результатов на проверке → задача руководителя;
- задачи без ожидаемого результата → задача руководителя;
- 3+ срочных задач → наблюдение качества приоритетов.

Эти пороги являются продуктовой стартовой логикой и позже должны настраиваться под компанию/отдел.
