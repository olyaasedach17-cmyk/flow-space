# Milestone 10 — End-to-end AI workflows

Этот этап соединяет интеграции Google Sheets, AI и готовый рабочий артефакт в один сценарий.

## Что добавлено

- `AI Workflow Studio` внутри раздела Integrations.
- Сценарий: **Google Sheets → AI-анализ → DOCX/PPTX/social post → сохранение в задачу**.
- Пользователь явно задаёт spreadsheet ID, диапазон, цель и тип результата.
- Данные таблицы ограничиваются по строкам/столбцам/размеру ячеек перед передачей AI.
- AI обязан вернуть структурированный JSON: summary, insights, recommendations, tasks, slides, report sections и social post.
- Новый защищённый `/api/artifacts` создаёт файлы на сервере без внешних офисных SDK:
  - PowerPoint `.pptx`;
  - Word `.docx`;
  - текстовый файл для social post.
- Файл скачивается пользователем только после явного запуска workflow.
- Результат можно привязать к существующей задаче. В задачу сохраняются источник, диапазон, число строк, выводы, рекомендации и имя файла.
- Автономное массовое чтение таблиц по расписанию не включено: действие запускает пользователь.

## Безопасность

- Google OAuth token остаётся на сервере.
- `/api/artifacts` требует Firebase ID token.
- AI получает только выбранный пользователем диапазон Google Sheets.
- Размер передаваемых данных ограничен.
- AI-result проходит структурную валидацию до создания файла.

## Следующее развитие

- Google Drive/Docs как контекст workflow.
- Google Calendar как источник дедлайнов/встреч.
- создание задач из AI-рекомендаций одним подтверждением;
- сохранение созданных файлов в Google Drive;
- визуальные шаблоны презентаций и бренд-настройки компании;
- изображения для social post через отдельный image-generation provider.
